# M Zohaib Khalid — Portfolio

A futuristic dark developer portfolio built with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` in your browser, or use the VS Code Live Server extension.

## Customize
- Replace GitHub and LinkedIn placeholder URLs in `index.html`.
- Update text, projects and experience as needed.
- Add your own images inside `assets/` if you later want them.
- The Font Awesome and Google Fonts resources are loaded from CDNs.

## GitHub Pages
1. Create a repository named `YOUR_USERNAME.github.io`.
2. Upload all project files.
3. Go to Settings → Pages.
4. Select `Deploy from a branch`.
5. Select `main` and `/ (root)`.
6. Save.
